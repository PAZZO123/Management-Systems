# Management Systems in C++

Console programs written in C++ to practise data structures and object-oriented programming.

## Programs

- `library.cpp`: library management
- `Hospital management System.cpp`: patient records
- `student record management system.cpp`: student records
- `event.cpp`: event management
- `Bank Queue Simulation.cpp`: a queue simulation
- `texteditorv2.cpp`: a simple text editor

## How to run

```bash
g++ library.cpp -o library
./library
```

Use the same steps for any other file.
